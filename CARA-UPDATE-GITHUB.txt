CARA UPDATE REPO GITHUB (nudin93/simposyandu) — 2 menit

OPSI A — lewat web (paling mudah, tanpa git):
1. Buka github.com/nudin93/simposyandu (login dulu).
2. Klik tombol hijau '<> Code' -> tab 'Upload files'... atau:
   buka tiap folder? TIDAK PERLU. Cara cepat: klik 'Add file' >
   'Upload files' hanya bisa per direktori. Untuk update BANYAK file
   sekaligus, pakai OPSI B (git) di bawah.

OPSI B — lewat git (disarankan, di laptop/PC yang ada git):
1. git clone https://github.com/nudin93/simposyandu.git (sekali saja)
2. Extract ZIP ini ke DALAM folder hasil clone > Overwrite semua.
   JANGAN timpa/ikutkan: config/credentials.php (tidak ada di ZIP ini).
3. cd simposyandu && git add -A && git status (cek yang berubah)
4. git commit -m "Update v26.11.0: tampilan + halaman seragam ala Penduduk"
5. git push origin main

CATATAN:
- credentials.php, foto uploads/, error_log, cache update TIDAK ikut di ZIP
  ini (sesuai .gitignore) — data server aman, tidak bocor ke publik.
- .htaccess versi repo (tanpa baris cPanel) yang dipakai; handler PHP cPanel
  tetap milik server, tidak ikut ke-commit.
- Setelah push: di server, git pull (atau upload ZIP biasa) + Ctrl+Shift+R.
- Versi baru 26.11.0: popup 'Yang Baru' otomatis muncul di semua perangkat.
