SIMPOSYANDU PRO-MODERN — PAKET SIAP TIMPA
==========================================
Isi ZIP ini LANGSUNG file aplikasi (includes/, assets/, modules/, dst + .htaccess).
TIDAK berisi: database .sql, uploads/, credentials.php, file .bak/.zip.
Aman untuk timpa — data tidak hilang.

CARA TIMPA YANG BENAR (cPanel File Manager):
1. Backup dulu (Compress folder simposyandu).
2. Upload SIMPOSYANDU-siap-timpa.zip KE DALAM public_html/simposyandu/
   (bukan ke public_html/).
3. Klik kanan zip > Extract > biarkan di public_html/simposyandu/ > Overwrite.
4. PENTING: pastikan TIDAK terbentuk public_html/simposyandu/simposyandu/.
   Yang benar: includes/, assets/, modules/ langsung di dalam simposyandu/.
   Jika terjadi folder ganda, pindahkan isinya keluar lalu hapus folder ganda.
5. Pastikan file ".htaccess" ada di dalam simposyandu/.
6. Buka https://domainanda/simposyandu/index.php + Ctrl+Shift+R.
7. CEK VERSI: bawah sidebar harus ada tulisan "v26".
   Jika tidak ada v26 = file lama yang tampil = ulangi langkah 2-4.
